## Предпросмотр

![Учебная студия LazyChess](../docs/images/app.png)

Карта позиции, учитывающая специфику каждой игры, разделяет точный контроль полей и контакты фигур, рассчитанные маршруты и оценки размена только по контакту, авторские планы и ограниченные варианты движка. Наведение или фокус показывает те же доказательства без хода; игру меняет только явное подтверждение. Все 11 языков приложения строго совпадают по ключам каталога и параметрам; арабский также переключает документ справа налево.

## Три набора правил

| Режим | Детерминированная власть | Текущая граница |
| --- | --- | --- |
| Международные шахматы | `chess.js` 1.4.0 | Стандартная легальность, шах, рокировка, взятие на проходе, превращение, мат и определение ничьей библиотекой |
| Сянци | Авторский адаптер TypeScript | Учебное ядро: движение, блок ноги коня, экраны пушки, река, дворец, встреча генералов, безопасность при шахе и поражение без ходов; решения по повторению/преследованию отложены |
| Сёги | Авторский адаптер TypeScript | Учебное ядро: движение, сбросы, фигуры в руке, превращение, нифу, безопасность при шахе и поражение без ходов; повторение, вечный шах и мат сбросом пешки отложены |

Помощник объясняет, но не ходит. Необязательные движки дают только ограниченные доказательства и никогда не меняют авторитетное состояние.

## Карта позиции и анализ

- **Контроль** показывает атаки и защиты по правилам каждой игры: атаки пешек, экраны пушки и блок ноги коня в сянци, а также сбросы в сёги отдельно от легальной подвижности.
- **Безопасность** отмечает защищённые, атакованные, незащищённые, спасённые и вновь подставленные фигуры, не выдавая один лишь контакт за доказанное взятие.
- **Линии** рисуют характерные для варианта маршруты дальнобойных фигур, открывшиеся линии, экраны пушки и зоны превращения — а не облако владения из го.
- **Зона короля** сравнивает поля под шахом, вражеские поля вокруг короля и точно легальные поля его перехода, включая ограничение «лицом к лицу» для генералов сянци.
- На новой доске предлагается одна учебная идея, явно помеченная как гипотетическая. Наведение, фокус или касание сравнивает позицию до и после; правая кнопка мыши или Escape убирает просмотр; только **Подтвердить** меняет состояние.
- Stockfish и Pikafish могут добавить ограниченные данные оценки и основных вариантов (PV) специализированных движков. Fairy-Stockfish явно помечен как классический резервный движок для сёги. Каждая движковая линия указывает перспективу стороны корневой позиции, лимит поиска, глубину, число узлов, время, происхождение исходников/бинарного файла и несопоставимую между вариантами игры внутреннюю шкалу оценки движка.

## Быстрый старт

Требуется Node.js `^20.19.0` или `>=22.12.0`.

```bash
npm ci
npm run dev
```

Vite по умолчанию привязывается к loopback. Выбор языка хранится через явный список из 11 разрешённых значений; неизвестные значения безопасно возвращаются к английскому.

## Детерминированный учебный договор

- ID варианта связывает полное состояние, действующего игрока и каноническое действие.
- Просмотр выводит неизменяемое состояние и никогда не пишет в хранилище.
- Устаревший, неизвестный, принадлежащий не тому игроку или выбранный после завершения вариант закрыто отклоняется.
- Точные, рассчитанные, авторские, движковые, модельные утверждения и аналогии сохраняют отдельные метки происхождения.
- Ответы на ходы-кандидаты — это ограниченные примеры форсирующих признаков, а не варианты движка или принудительные прогнозы; оценки материала используют явно заданную авторскую шкалу ценности фигур.
- Анализ привязан к полному токену состояния и действующему игроку. Устаревшие движковые или кандидатные данные отклоняются, а не перерисовываются поверх более новой позиции.
- Ограничения сянци и сёги остаются видимыми и не выдаются за полное судейство.

## Проверка

```bash
npm run check
git diff --check
```

Тесты охватывают характерные правила, анализ сёги с высоким коэффициентом ветвления, привязанные к состоянию кандидаты, неизменяемые предпросмотры, данные о взятии на проходе/пушке/генералах лицом к лицу/сбросе, идемпотентность, гонки сохранения, продолжение сессии, ограниченный протокол движка и безопасность путей, равенство 11 языков, сохранение языка, направление RTL и явное подтверждение.
